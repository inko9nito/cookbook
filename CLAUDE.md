# Cookbook — instructions for Claude

Personal recipe PWA for one user on an iPhone. Mobile-first, iOS-native feel. Full plan: `docs/PLAN.md`.

## v2: Ionic (milestone "v2: Ionic", issue #141)
The app moved from Framework7 to **Ionic React 9** (Nov 20, 2026), after hours of iPhone Safari not drawing Framework7's headers (#123, #141). The last Framework7 version is kept on the branch **`v1-framework7`** (what's live until v2 is done): read a v1 screen there (`git show origin/v1-framework7:src/pages/RecipePage.tsx`) when porting it or matching it. **v2 is built on the `v2` branch**: PRs go into `v2`, each with its deploy preview; `v2` merges into `main` (the live app) only once it has every v1 feature and matches it, when the user says so.
- Still to port from v1: reading a recipe from photos or a link (#17, #15), Import from Prepear (#14), Grocery Stores (#129), Edit Cover (#80) and photo cropping (#51, #59), a cookbook's section pages, the Style Guide. Each says "isn't in v2 yet" meanwhile.
- **Matching v1 (#141, PR into `v2`):** each screen was screenshot beside v1 on the same demo data (v1 built from `v1-framework7` and served beside v2) and measured element by element (size, position, font, weight, colour, corners, shadow). Where v1's own classes in `cookbook.css` style it, v2 uses them (a cookbook's header and shelves `.ck-book-hero`/`.ck-shelf*`, the Planner's `.ck-week-*`/`.ck-agenda`/`.ck-plan-*`, Groceries' `.ck-grocery-*`), with the Framework7 sizes they read defined on `:root` in `ionic.css` (`--f7-navbar-height` 48px…). v1's facts kept: the bar is 48px, the title black (`--ck-title`); **only Recipes, a cookbook and a recipe hide their title row on scroll** (`TabPage hides`); lists, sheets, cards and dialogs have v1's corners (16px lists, 32px sheets, cards and dialogs) and pill buttons; menus are 250px, centred under their button; Pick a day is drawn with the week strip's own day circles (`DaySheet`), not Ionic's date picker, under Ionic's style of month header (month and year on the left, ‹ › on the right: the user's pick); loading placeholders are v1's shapes (`src/ionic/Skeletons.tsx`) in `--ck-skeleton` with Ionic's shimmer; cook mode's Directions fades above the recipe tabs. The editor still needs porting (v2's is a stand-in).
